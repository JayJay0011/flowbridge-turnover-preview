# Flowbridge Serviced Accommodation Operations Preview

An interactive discussion concept showing how a serviced-accommodation team could track same-day turnover readiness across housekeeping, maintenance and guest communication.

All properties, people, statuses, times and integrations are fictional sample data. This is not a live client system and does not imply endorsement, purchase or adoption by any accommodation operator.

## Preview locally

```bash
python3 -m http.server 4174
```

Open `http://127.0.0.1:4174` from this directory.

## Demonstrated workflow

1. Select **Harbour View Apartment**.
2. Review the incomplete readiness checklist and open boiler-pressure issue.
3. Click **Mark repair as resolved**.
4. Confirm that the property status, summary counts, checklist and timeline update to Ready.

## Purpose

The preview is designed to start an informed workflow conversation. It is not positioned as a platform replacement. A real implementation would be based on the operator's existing process, tools, data access and approval.
